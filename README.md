# رتِّل — مصحف رقمي للقراءة والتدبر

موقع لقراءة القرآن الكريم كاملاً آيةً آية، مع التلاوة الصوتية، والتفاسير المعتمدة،
والإعراب، ومعاني الكلمات — ومتابعة تلقائية لموضع قراءتك.

## المزايا
- **المصحف كاملاً** بالرسم العثماني (خط مجمع الملك فهد — رواية حفص)
- **استماع** بأكثر من قارئ، مع تتابع تلقائي للآيات وتظليل الآية المتلوّة
- **تفاسير معتمدة**: الميسر، ابن كثير، السعدي، الطبري، القرطبي، البغوي، الوسيط
- **الإعراب** (الإعراب الميسر + إعراب الدرويش) و**غريب القرآن** لمعاني الكلمات
- **متابعة القراءة**: حفظ تلقائي لآخر موضع + نسبة الإنجاز لكل سورة وللمصحف
- علامات مرجعية، وضع ليلي/نهاري، تحكم بحجم الخط، تصميم متجاوب RTL

## التشغيل
```bash
# تشغيل MongoDB محلياً ثم:
npm install
npm run dev        # يشغّل السيرفر (5002) والواجهة (5173+) معاً
```

## البنية
- `client/` — React + Vite + Tailwind v4 (feature-based)
- `server/` — Express + Mongoose، وسيط مع كاش أمام Quran.com API و CDN التفاسير

## المصادر
- النص والصوت والتفاسير: [Quran.com API v4](https://api.quran.com)
- الإعراب وغريب القرآن: tafsir_api (CDN)
- الخط: KFGQPC Uthmanic Hafs — مجمع الملك فهد لطباعة المصحف الشريف
